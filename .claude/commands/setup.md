Bootstrap this project from the template.

Steps:

1. Read `docs/SETUP.md` in full — it is the authoritative setup guide.
2. If `docs/SETUP-PROGRESS.md` exists, read it and resume from the first
   unchecked step instead of starting over.
3. Follow the guide. It covers: gathering the project scope from the user,
   choosing the stack, updating the dev container, scaffolding the project,
   writing the PRD, and initialising Taskmaster.
4. Keep `docs/SETUP-PROGRESS.md` updated after every completed step so a new
   session (e.g. after a container rebuild) can pick up where you left off.
