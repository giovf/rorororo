### 1. Claude Connectors Directory — winner (11.0)

- **The shelf.** Anthropic's Connectors Directory lists remote MCP servers to every Claude user
  (claude.ai, Desktop, mobile, Claude Code, Cowork). Submission is a portal form on any **paid
  Claude plan** (the owner already has one — the routines run on it); after an automatic policy
  scan the server is **listed as a Community connector by default, with no reviewer gate**
  (https://claude.com/docs/connectors/building/submission; https://claude.com/docs/connectors/building/review-criteria).
  That is the first shelf since Apify that opens without a third party saying yes, and the first
  one where the buyer is the agent's owner sitting in the chat — the same population that
  produces our 80 paywall hits a day without ever finding the sign-up.
- **Evidence of paying demand.** Same buyers as gankdat's data (paid rivals PlanAPI, Searchland,
  ComplyAdvantage tiers; Apify actors at US$1–8/1k rows on identical registers — STRATEGY §2, W39
  doc). Directory metrics show rank, distinct accounts and tool calls, so the shelf measures
  itself (https://claude.com/docs/connectors/building/managing-your-listing).
- **Gap we fill.** Nobody in the directory serves UK/EU official registers as a connector
  (MCP Registry / mcpservers.org listings of ours are the only ones, and those are developer
  directories, not an end-user shelf).
- **What the server is missing today** (read from `src/mcp/server.ts`, `src/routes/mcp.ts`):
  1. every tool has a `title` but **no `readOnlyHint` / `destructiveHint`** — the portal flags
     that and reviewers reject it;
  2. **no Origin validation** on `/mcp` (an invalid `Origin` must get 403);
  3. **every tool must return a successful response with valid parameters** — today the 17 query
     tools and `get_changes` return a 200 `isError` "Authentication required" without a key, and
     an authless directory listing cannot carry a key. Smallest fix: a keyless **preview** —
     `limit ≤ 5` rows, 20 calls/day per client — so each tool answers, and the paywall message
     names the plan and the price after that. Stays consistent with the keyless 401 on REST;
  4. listing pack: docs URL (`/docs#claude`), privacy URL (`/privacy` exists), support contact
     (`info@gankdat.com`), 64×64 icon (PNG of the raccoon), a test key for reviewers, tool names
     ≤ 64 chars (longest is `query_uk_gambling_operators`, fine).
- **Build.** 0.75 day: annotations on 22 tools, Origin middleware, keyless preview cap in the
  MCP gate, `docs.html` section, icon, and a CI test `test/mcp-directory.spec.ts` that asserts
  title + hint on every tool, name length, Origin 403 and a 200 tool result for every tool
  without a key (this doubles as the conformance test for ChatGPT / Cursor listings later — the
  self-expansion angle). Owner: one portal form, ~20 min.
- **Proof.** Directory usage tab: ≥ 20 distinct Claude accounts used a tool in the first 30 days
  and ≥ 1 key issued to a claude.ai referrer; `/mcp` calls with the Anthropic egress range
  (`160.79.104.0/21`) in the Daily numbers row.
- **Risk.** A Community listing without OAuth cannot bill inside Claude — buyers must take the
  key from `/account` and use it from another client until #2 ships. Acceptable: the listing is
  the discovery; #2 is queued right behind it.

### 2. Lazy OAuth for the MCP server — queued second (8.0)

Claude (and ChatGPT's Apps SDK, and Cursor) start sign-in only on an HTTP 401 with
`WWW-Authenticate: Bearer resource_metadata=…`; a 200 tool error never does
(https://claude.com/docs/connectors/building/lazy-authentication;
https://claude.com/docs/connectors/building/authentication). gankdat has magic-link sessions and
API keys but no authorization server. Build: `/.well-known/oauth-protected-resource[/mcp]` and
`/.well-known/oauth-authorization-server`, `/authorize` (CIMD — fetch Claude's client_id URL,
check redirect_uri incl. port-agnostic loopback — with consent rendered on the magic-link session),
`/token` (PKCE S256, form-urlencoded, refresh rotation, 10 s budget), tokens mapped to the
account's default key so plans and credits apply, and the 401 gate on protected tool calls.
1.5 days, no owner minutes. Proof: first key connected from claude.ai; paywall → checkout
conversion measurable per client. Also what the ChatGPT directory would need.
