# Run log

One line per routine run, newest last; every new line is sent to the owner's Telegram by the
`notify owner` CI job. Format: `- YYYY-MM-DD HH:MM | <routine> | <one-liner, ≤ 120 chars>`.
Routines: build, exchange, review, report. Keep it to 1–3 lines per run.
