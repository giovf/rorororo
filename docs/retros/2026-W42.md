## 7. Proposals

**1. Land a first-run check for every newly installed workflow.** Observation: `demo-video.yml`
failed twice on its first live runs (INBOX 2026-10-11 20:11, 20:19), `pr-relay.yml` never fired
for the request it was built for (RUNS 10-11 19:24), and the 10-16 landing deploy failed 13 s in
(INBOX 10-16 18:25) — the first live run of new CI is how defects surface, and the interactive
session pays for each. Fix: add one sentence to `docs/routines/burn-down.md` and
`docs/routines/build.md`, after the step that writes to `docs/ci/`: "When the next slot finds the
installer commit (`ci: install workflow(s) <name>`) for a workflow you wrote and it has a
`workflow_dispatch` trigger, dispatch it once with `mcp__github__actions_run_trigger`, read the
conclusion with `actions_get`, and append `- … | <tag> | <name> first run: <success|failure +
failing step>` to `docs/RUNS.md`; on failure fix it in that same run, not a later one."
`effort_days` 0.2. Proof: for the 14 days after landing, every `ci: install workflow(s)` commit
for a routine-written workflow has a `first run:` RUNS line within 1 day, and zero INBOX `Run
failed` lines name a workflow within an hour of its installer commit. Score: evidence 3 × reach 2
(build + burn-down) ÷ 0.2 days → **5**.

**2. Make triage reconcile figures against the ledger before it escalates a bill.** Observation:
two `owner:` lines this week (ALERTS 10-12 Nebius, 10-13 Cloudflare $49) asked the owner to check
what the repo already stated, contradicting `docs/routines/inbox-triage.md` line 34 ("`needs
owner` is reserved for things only the owner can do"). Fix: append to that `WHO DOES WHAT`
paragraph: "A mail that states an amount or a status the repo already records (`docs/LEDGER.md`,
a venture's `RESEARCH.md`) is reconciled against that file first and logged with the matching
row; it is `needs owner` only when the amounts differ or the action needs the owner's identity,
card or login." `effort_days` 0.1. Proof: over the following 4 weeks, no `owner:` line in
`docs/ALERTS.md` is later closed `Done` with "already in the ledger" or "answered from the repo".
Score: evidence 2 × reach 2 (triage runs hourly, every bill mail) ÷ 0.1 days, capped by the
frequency (2 in 7 days) → **4**.
