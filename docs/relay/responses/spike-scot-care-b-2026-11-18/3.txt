Datastore (as at 31 March 2026) (https://ci-web-media-production-bucket.s3.eu-west-2.amazonaws.com/assets/resources/datastore/260331datastoreexternal.csv)
Published: 14 April 2026
The Datastore is available to download in two formats:
an excel XLSX format which contains some pre-prepared pivot tables to assist with data analysis
CSV format which only contains the data.
These files are updated monthly.
There is also a tab available in the XLSX file which has definitions and notes on each of the data fields and it is recommended that this is used alongside the data as a reference.
All content is available under the Open Government License (https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/) , unless otherwise stated.
