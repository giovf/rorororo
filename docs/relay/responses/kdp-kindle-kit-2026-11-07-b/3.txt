Want to start building with Claude Code today - not next week? This concise, quick start guide gets you from install to productive in a single sitting.
Claude Code is Anthropic's agentic coding tool: instead of autocompleting one line at a time, it reads your whole project, edits files, runs commands, and works through real tasks while you steer. This book shows you exactly how to put it to work.
Inside, you'll learn how to:
Install Claude Code on macOS, Linux, Windows, or WSL and sign in
Run your first session: explore a codebase, make changes, and use Git through plain English
Write prompts that get great results the first time
Use Plan Mode and permission modes to stay in control
Manage the context window so Claude stays fast and accurate
Set up CLAUDE.md so Claude knows your project's conventions
Create skills, slash commands, and subagents to tailor the tool to your workflow
Connect external tools with MCP
Work inside the official VS Code extension (also runs in Cursor)
Written for developers new to agentic coding, this is the fast on-ramp: focused, hands-on, and verified against the current official documentation.
This is an independent, unofficial guide and is not affiliated with or endorsed by Anthropic.

Install & sign in on macOS, Linux, Windows, or WSL

I'm a software engineer with more than 20 years of experience building web and mobile applications — across government contracting, the energy sector, workforce management, and independent freelance work. Most of that work has been in Angular, TypeScript, and Node, with a lot of full-stack development and UI design along the way.
These days my focus is on AI-assisted development. I use Claude daily, build applications on the OpenAI APIs, and run local models through tools like Ollama.
I've always learned best from material that gets straight to the point, so that's what I set out to write: clear, practical guides to the tools I actually use — from Claude Code to modern web development — with no filler, built to get you productive fast.
Everything I write is grounded in real-world experience and designed to give you skills you can put to work the same day.
If something I write helps even one person level up their skills, that's a win in my book.
