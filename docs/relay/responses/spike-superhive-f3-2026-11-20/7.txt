TACHYON STUDIO
Blender Preview
Save detailed viewport thumbnails inside .blend files and browse them in Windows Explorer.
Version 0.5.1 · Windows x64 · Legacy + Extension installers
Find the file by its view
A familiar filename is not always enough to identify the right project. Frame your subject, save, and give the file a useful visual reference. Blender Preview captures the 3D view you are working in and stores that image inside the .blend file, ready for Windows Explorer's thumbnail views.
A preview worth saving
Keep the subject visible. Capture the viewport without the timeline, Outliner, Properties editor, toolbar or sidebar. Turn off viewport overlays when you want a clean image.
Choose the detail. Store a 512, 1024 or 2048-pixel preview on its longest edge. The default is 1024; rendering at twice the output dimensions smooths edges before the image is stored.
Use your normal save workflow. Ctrl+S, Save As and the compact Save Preview button trigger capture. Your current view determines the image even when the scene has a camera.
Keep setup out of the way. A small sidebar provides daily actions. Preview, Explorer and Support preferences organize settings, Windows registration, restoration and help.
[A real viewport preview embedded by Blender Preview]
From viewport to file
Install the package matching your Blender version and enable Explorer thumbnails in its preferences.
Frame the subject in the 3D Viewport and choose the capture resolution.
Save the .blend file, then open its folder.
Use Large or Extra large icons in Explorer and refresh the folder.
Included downloads
blender-preview-0.5.1-extension-blender-4.2-5.2-windows-x64.zip — complete native Extension for Blender 4.2–5.2, source and license notices.
blender-preview-0.5.1-legacy-blender-3.0-4.1-windows-x64.zip — the same complete add-on for Blender 3.0–4.1 in legacy format.
blender-preview-0.5.1-documentation.zip — illustrated quick start, offline manual, FAQ and release notes.
Install only one installer. Both purchase options include both formats and the same complete feature set. No model library is included.
Compatibility and practical limits
Blender 3.0–5.2 on Windows x64. Tested builds: 3.0.1, 3.1.2, 3.2.2, 3.3.21, 3.4.1, 3.5.1, 3.6.23, 4.0.2, 4.1.1, 4.2.23, 4.3.2, 4.4.3, 4.5.13, 5.0.1, 5.1.2, 5.2.0. Testing covers one patch build from every minor series in this range; other patch builds and future versions have not been individually verified.
A 3D Viewport must be open when capturing. Existing files need to be opened and saved again; this release does not batch-convert a library. Compressed files are recompressed, so allow extra disk space and save time. Higher resolutions increase file size and GPU work.
Explorer controls its own display size and cache. Refreshing or reopening the folder may be necessary. The tool supplies icon thumbnails, not an interactive Preview pane. macOS, Linux and Windows ARM64 integration are outside this release.
