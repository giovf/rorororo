Convert Blender Cloth, Soft Body, and Alembic mesh sequence caches directly into editable shape keys to manually refine physics simulations. This Blender shape key animation tool eliminates the need to infinitely tweak solver settings by allowing you to bake simulations to keyframes, sculpt out collision errors, and seamlessly export Blender cloth to game engines like Unreal Engine and Unity.
The Artist-Driven Workflow
Simulate: Run your standard physics solver or import an Alembic mesh sequence.
Bake: Convert the simulation to shape keys using custom frame-stepping and interpolation.
Sculpt & Edit: Fix mesh intersections, adjust timing, or stylize folds directly in Edit Mode or Sculpt Mode. The add-on isolates the correct pose based on your playhead position automatically.
Retime: Move, delete, duplicate, overlap, or Insert(from mix) timeline keyframes. The add-on dynamically rebuilds transitions to ensure smooth blending between surrounding keys.
Export: Treat the simulation as a starting point, refining it into a lightweight, baked asset ready for external pipelines.
Technical Specifications & Features
Supported Source Data: Native Cloth modifiers, Soft Body physics, and Alembic (Mesh Sequence Cache).
Flexible Frame Sampling: Bake every frame for 1:1 fidelity, or sample every N frames to optimize file sizes. Choose between linear (smooth) or stepped motion interpolation.
Smart Timeline Editing: Delete unwanted simulation moments or insert new poses from a mix of shapes while the underlying F-curves automatically bridge the gap to prevent animation popping.
Data Management: Prevent bloat with pre-bake shape key count estimations. Organize your outliner using custom prefix assignments, custom output naming, and automatic hiding of the original source meshes.
Software Requirement: Fully compatible with Blender 4.0 to newer 5.2.
