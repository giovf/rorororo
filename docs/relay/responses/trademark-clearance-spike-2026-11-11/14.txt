Search by Nice class
One or more classes of goods and services, separated by commas, may be specified using class numbers.
When you start typing a specific good or service, it will be matched with those in the 45 class headings, if found. To specify the correct class of the goods and/or services, click the "Navigate through all goods and services" link that will open a new tab in your browser and launch TMClass.
If more than one class is selected, an option to choose between OR/AND/NOT will appear. The option 'OR' is the default value and will retrieve trade marks which contain at least one of the chosen classes. If 'AND' is selected, the retrieved trade marks will contain all of the chosen classes. Select 'NOT' when you want to exclude trade marks with the chosen class.
* Please be aware that the Nice class cannot be used alone as a search criterion. It has to be combined with at least one more criterion.
