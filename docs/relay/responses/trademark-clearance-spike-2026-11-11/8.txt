Description
JSON example
Max Trademarks
maxTrademarks
Optional
#maxTrademarks
Maximum number of trademarks to collect. The combined registers hold over 145 million marks, so for large pulls narrow the search with the filters below.
Type: integer
Minimum: 1
Maximum: 5000000
Trademark Text
markTexts
Optional
#markTexts
One or more brand names or mark words to search for. Each entry runs as its own search and the results are merged and de-duplicated.
Type: array
Owner / Applicant Name
applicantNames
Optional
#applicantNames
One or more trademark owners to search for, for example "Nestle" or "Siemens". Each entry runs as its own search.
Type: array
Match Mode
matchMode
Optional
#matchMode
How the trademark text is matched. "Contains" is the widest, "Exact" the narrowest, "Fuzzy" also catches near-identical spellings used in clearance searches.
Type: string
Default: contains
Options:
contains exact beginsWith word fuzzy
Trademark Offices
offices
Optional
#offices
Restrict the search to specific registers. Leave empty to search all 77 offices at once. Use the two-letter office code, for example US, EM (European Union), CN, GB, DE, BR, JP, WO (Madrid international).
Type: string[]
Item
Protected In (Territory)
territories
Optional
#territories
Keep only marks that are in force in these territories. Useful for EU-wide and Madrid marks, whose protection reaches far beyond the office that issued them. Two-letter country codes.
Type: array
Nice Classes
niceClasses
Optional
#niceClasses
Restrict to these Nice classification classes (1-45), for example 9 for software, 25 for clothing, 35 for advertising and business services.
Type: array
Status
trademarkStatus
Optional
#trademarkStatus
Restrict to marks in these states. Leave empty for all.
Type: string[]
Item
Mark Type
trademarkTypes
Optional
#trademarkTypes
Restrict to these kinds of mark, for example word marks only or figurative marks only.
Type: string[]
Item
Vienna Codes
viennaCodes
Optional
#viennaCodes
Restrict figurative marks to these Vienna classification codes, for example 26.11.12 for horizontal stripes.
Type: array
Filed From
applicationDateFrom
Optional
#applicationDateFrom
Only marks filed on or after this date (YYYY-MM-DD).
Type: string
Filed To
applicationDateTo
Optional
#applicationDateTo
Only marks filed on or before this date (YYYY-MM-DD).
Type: string
Registered From
registrationDateFrom
Optional
#registrationDateFrom
Only marks registered on or after this date (YYYY-MM-DD).
Type: string
Registered To
registrationDateTo
Optional
#registrationDateTo
Only marks registered on or before this date (YYYY-MM-DD).
Type: string
Fetch Full Record
fetchFullRecord
Optional
#fetchFullRecord
Open each mark's full register record for goods and services wording, priority and seniority claims, oppositions with grounds and earlier marks, publications and status history. Turn off for a faster, lighter list-only run.
Type: boolean
Default: true
Fetch Owner & Representative Details
fetchPartyDetails
Optional
#fetchPartyDetails
Also look up the owner and representative postal address at the publishing office. Available for many offices; a few publish party details only through a channel that refuses automated requests, and those rows are flagged instead of guessed.
Type: boolean
Default: true
Goods & Services Language
goodsServicesLanguage
Optional
#goodsServicesLanguage
Preferred language for the goods and services wording, as a two-letter code. Falls back to English, then to whatever the office published.
Type: string
Default: en
