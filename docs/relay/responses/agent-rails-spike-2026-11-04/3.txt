Seller Guide
What a seller agent is, how to create one, and how to manage it once you're accepting KYAPay tokens.
Selling on Skyfire means letting buyer agents transact with a resource you run, using KYAPay tokens. This page covers the steps you take on Skyfire, and the enforcement you build on your own side.
What is a seller?
#what-is-a-seller
A seller agent is an agent account that publishes seller services and accepts KYAPay tokens from buyer agents. Buyer agents are created automatically at signup. A seller agent is not, so you create one explicitly.
A seller agent:
Belongs to exactly one user, and always has the Seller role
Creates a seller service , the resource it publishes
Receives every token a buyer agent creates for that seller service
Charges payment tokens
Has its own wallet , where charged funds settle
Can be managed in the Skyfire Dashboard, or accessed programmatically through its own API keys
An agent's role is fixed at creation. A seller agent cannot create tokens, and a buyer agent cannot charge them. For how sellers fit into the wider platform, see Platform Structure (/docs/platform-structure) .
Your email identifies you on Skyfire. The same account can hold a buyer agent and any number of seller agents, each with its own wallet and API keys, and each key authorizes a different set of calls: a buyer agent's key creates tokens, and a seller agent's key verifies and charges them. Adding a seller agent to your account does not replace or affect any agent you already have.
Create a separate seller agent for each business you run on Skyfire, for example one per store or brand, so that each has its own services, settlement wallet, and ID.
Seller agents publish seller services for buyer agents to find and transact with. See How Seller Services Work (/docs/seller-services) for what it configures, how to create one, and how to require and validate its tokens on your own backend.
Setting up on Skyfire
#setting-up-on-skyfire
Create your seller agent
#create-your-seller-agent
From the Skyfire Dashboard (https://app.skyfire.xyz) , click Create a Seller . The button is available whether or not you already have a seller agent, so you can add as many as you need.
Enter a Display Name , which is the name buyer agents see in the directory. It must be unique among your active agents. Skyfire then creates the seller agent, creates its wallet, and opens the seller view for it. If you hold more than one seller agent, use the agent switcher in the upper-left corner to choose which one you are managing.
Your seller agent also has a unique ID, which you use during verification. Every token created for your seller service carries it as the aud claim.
Once your seller agent exists, create a seller service, configure it, and submit it for approval. See How Seller Services Work (/docs/seller-services) for details.
Managing your seller agent
#managing-your-seller-agent
Your dashboard organizes each seller agent's activity into two tabs. Switch between seller agents with the agent switcher.
API keys
#api-keys
Generate API keys to authenticate your seller service, and view, rotate, or deactivate them as needed. These keys authorize charges on pay and kya-pay tokens, among other seller capabilities. These seller agent API keys are separate from any buyer agent API keys on the same account. See API Authentication (/reference/api-authentication) .
Deposits
#deposits
The Deposits tab shows every successful payment to your seller service: the token used, the buyer agent ID, the amount charged, and the timestamp and status.
Next steps
#next-steps
For creating and configuring a seller service, see How Seller Services Work (/docs/seller-services) .
For how money moves after a charge, see Payments & Settlement (/docs/payments-settlement) .
