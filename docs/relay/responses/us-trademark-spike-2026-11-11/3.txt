Open Data Portal Registration Requirement​
In order to access the Open Data Portal (ODP), starting on June 18, 2026 , you'll need to sign in with a valid USPTO.gov account. Please sign in using the navigation below or create an account using the button in the banner. If you want more information on this initiative, please visit our Register for ODP access page (support/universal-registration) and sign-in today. Additionally, your USPTO.gov account requires multi-factor authentication (MFA). For guidance on MFA setup, please visit the USPTO.gov account FAQs (https://www.uspto.gov/learning-and-resources/account-faqs#subcategory=&category=Multifactor+authentication) .
Also, effective August 18, 2026 , users are required to provide four additional fields of information on their USPTO profile. API keys for accounts that did not complete these fields by October 8, 2026, have been deactivated. To reactivate your key, update these fields in your USPTO.gov account (https://account.uspto.gov/profile) settings by selecting the “Open Data Portal” section at the bottom of the left navigation menu. Next login to ODP and click on the Activate API Key button on the Manage API Key page. See our FAQs (/support/faq) for details.

What is the ODP API?
The Open Data Portal (ODP) API allows you to access USPTO data at no cost – with several ways to do it.
The ODP API uses HTTP, GET, and POST requests to return responses in JSON format. ODP also provides REST APIs, which provide rich search capabilities and allow users to retrieve patent application data, continuity data, documents, patent term adjustment data, and much more. You must get an API Key to use the ODP API.
Note: The data products on our website allow users to download data without the need for an API key. Using ODP APIs will require an API key.
Resources for APIs:
The API Syntax Examples (/apis/api-syntax-examples) section is helpful for a “quick start” and may be used by more casual users to flexibily search the same data available on the Patent File Wrapper.
The Swagger UI (/swagger/index.html) [swagger icon] has examples, schemes, and more to test out ODP APIs for Patent File Wrapper and Bulk Data Directory. Note that you will need your ODP API key to use the Swagger UI.
The Open Data Portal Simplified Query Syntax Documentation (/documents/documents/ODP-API-Query-Spec.pdf) includes defined keywords, POST and GET search request guides, field dictionary, and FAQs.
The Field Dictionary (/documents/documents/patent-data-schema.json) is a schema document that shows data fields and dataset JSON structures that ODP uses.
The Patent File Wrapper APIs (/apis/patent-file-wrapper/search) and Bulk Data Directory APIs (/apis/bulk-data/search) document all available endpoints with their respective JSON Response examples and data property information for each return response.
The API Transition Guidance (/support/transition-guide/peds) will help you transition from using the Patent Examination Data System (PEDS) and Bulk Data Storage System (BDSS) to the Open Data Portal (ODP).
The PEDS-to-ODP API Mapping (/documents/documents/PEDS-to-ODP-API-Mapping.pdf) and BDSS-to-ODP API Mapping (/documents/documents/BDSS-to-ODP-API-Mapping.pdf) will be helpful for API endpoint transition.
How do I get an ODP API key?
To use the ODP API, you must have a registered USPTO.gov account and a validated and linked ID.me account to request an API Key. This API Key will allow the USPTO to manage and track data threshold limits, providing sustainable access to USPTO data for all customers. Follow the steps below to obtain your API Key.
Note: If you have any questions that can’t be answered in the FAQs, please contact us. (/support/contact)
1. Create your USPTO.gov account
If you do not already have a USPTO.gov account, please complete the following steps:
Visit https://account.uspto.gov to create a USPTO.gov account.
Complete the required fields and accept the USPTO terms of use (https://www.uspto.gov/terms-use-uspto-websites) and privacy policy (https://www.uspto.gov/privacy-policy) , which apply to the Open Data Portal APIs. You are required to adhere to these terms of use.
Please be sure to update the additional ODP product specific fields in your USPTO.gov account. These can be found under the Open Data Portal section of the account settings page.
Check your email for an activation code. Note that this code expires in 48 hours.
Activate your account using the link in your email.
2. Create your ID.me account
Create an ID.me account by navigating here (https://api.id.me/en/registration/new) and completing the required steps.
Complete the required fields and submit the required documents to start your verification process with ID.me. You can verify using self-service, which is a guided process, or with a live agent during a video call.
Note for international users:
If you live outside the United States, you’ll need to verify your identity on a video call. Learn more from ID.me’s Video Call article. (https://help.id.me/hc/en-us/articles/4415907236375-Verifying-if-you-live-outside-of-the-United-States)
You will also need to submit an English-translated version of your documents if not already in English. Troubleshoot document upload issues with ID.me’s fix rejected documents article. (https://help.id.me/hc/en-us/articles/360058791094-How-to-fix-rejected-documents)
3. Link your USPTO.gov account and obtain your API Key
With both USPTO.gov and ID.me accounts created, click the “Manage API Key” button in the ODP navigation.
Once signed in, a page with information on how to link your USPTO.gov and ID.me accounts will be available. That page holds additional instructions on sign-in if needed. To link the accounts please click the “Verify MyUSPTO.gov account with ID.me.” Follow the guidance enclosed.
This guided process will automatically link your ID.me account to your USPTO.gov account, which is a one-time registration.
Once your accounts are linked, a final page will display a button to request API Key access. Click this button to view your personal API Key information.
Notes:
This will be the same API Key you always use to access Open Data Portal APIs.
There can only be one API Key per account. Do not share it with others. It is an identifier unique to you.
Your Key shouldn't expire if it is used at least one time per year. If your API Key expires, you will be provided instructions on how to renew it.
Your API Key will always display on the Manage API Key (/apikey/key-reveal) page, so you can view it at any time (when logged in to your USPTO.gov account).
You do not have to be logged in to your USPTO.gov account to use the API Key. You just need to be logged in to view it.
4. Start using your API Key to request patent data
Once you have obtained your API key, you can start using the Open Data Portal APIs via the Open Data Portal API Syntax Examples (apis/api-syntax-examples) page.
Find resources and documentation depending on how you want to use the APIs:
Simple use cases
See the API Syntax Examples (/apis/api-syntax-examples) section for simplified syntax examples and a link to additional documentation.
Advanced use cases
See advanced syntax examples and documentation in Swagger UI (/swagger/index.html) [swagger icon] .
Note that there are additional examples for each API endpoint under the ODP Patent Data section (such as Application Data (/apis/patent-file-wrapper/application-data) , Continuity (/apis/patent-file-wrapper/continuity) , etc.).
Here is a sample format of where you should add your API key in the HTTP header:
x-api-key as “x-api-key: < api-key >”
-H 'X-API-KEY: <YOUR_API_KEY>'
For example:
curl -X 'GET' \ 'https://api.uspto.gov/api/v1/patent/applications/search' \
-H 'accept: application/ json' \ -H 'X-API-KEY: <YOUR_API_KEY>'
If you have any questions or errors, please visit the FAQs (https://data.uspto.gov/support/faq) page for assistance.
Unused API Key and Deletion Policy
If an ODP API key remains unused for 90 days, it will be deleted.
If your API key is deleted and need a new API key, please visit Manage API Key (/apikey/key-reveal) page to obtain a new one.
