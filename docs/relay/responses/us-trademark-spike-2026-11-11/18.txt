README (/accountable_eel/trademark-filing-watch) Input (/accountable_eel/trademark-filing-watch/input-schema) Output (/accountable_eel/trademark-filing-watch/output-schema) Pricing (/accountable_eel/trademark-filing-watch/pricing) API (/accountable_eel/trademark-filing-watch/api/python) Issues (/accountable_eel/trademark-filing-watch/issues/open)
Watch USPTO and EUIPO for new trademark applications that contain or resemble your marks, by Nice class. One row per filing with the owner, classes and a record link. Monitoring bills only new matches, and can alert Slack, Discord or Telegram. No API key and no proxy. EUIPO is searched through TMview ( adFrom / adTo ). If USPTO later requires a token, the fallback is the official bulk daily XML on bulkdata.uspto.gov; that path is not built yet.
How to use #how-to-use
In the Apify Console. Open the actor page and click Start — the terms field is already pre-filled with a working example. Results land in the run's dataset as soon as each item is found.
Via the API. Call it directly with a POST request — no Console needed once you have an API token:
curl "https://api.apify.com/v2/acts/accountable_eel~trademark-filing-watch/run-sync-get-dataset-items?token=<YOUR_TOKEN>" \
-X POST \
-H "Content-Type: application/json" \
-d '{"terms":["cloud"]}'
On a schedule. Save this actor as an Apify Task with the input you want, then add a Schedule (hourly, daily, weekly) so it runs on its own — no server of your own required.
Input #input
{
"terms" : [
"cloud"
]
}
One mark per line. Each line is searched on its own. By default a filing matches when the word mark contains the term. Accepted formats: cloud, ClassCloud, your brand.
Example runs #example-runs
For brand owners and IP attorneys. Change the field named in each note.
1. Watch my brand (who: brand protection). Change terms .
{ "terms" : [ "yourbrand" ] , "matchMode" : "similar" , "onlyNewSinceLastRun" : true }
2. New software trademarks in classes 9 and 42 (who: agency lead-gen). Change classes .
{ "terms" : [ "ai" ] , "classes" : [ 9 , 42 ] , "sinceDays" : 7 }
3. New filings by keyword (who: a category watch). Change terms .
{ "terms" : [ "coffee" ] , "classes" : [ 30 , 43 ] , "sinceDays" : 14 }
Output #output
One row per item, for example:
query	found	status	filingCount	filings	searchSummary	monitorStatus	truncated	notifyErrors	office	serialNumber	mark	matchType	similarityScore	filedDate	liveStatus	statusCode	ownerNames	niceClasses	goodsAndServices	recordUrl	isNew	firstSeenAt	scrapedAt
cloud	true	OK	<all filings (full list)>	<is this filing new?>	1970-01-01T00:00:00.000Z
A miss comes back as a row with "found": false and is never charged.
Pricing #pricing
New trademark filing matched : $10 per 1,000 filings
Plus a $0.002 start fee per run. Each event above is billed independently, only when it actually returns data — misses ( found:false ) are never charged.
Use it from Clay, n8n, Make, or an AI agent #use-it-from-clay-n8n-make-or-an-ai-agent
This actor runs synchronously over plain HTTP — call it directly from a script, a workflow tool, or an AI agent, no Apify Console needed once you have an API token.
curl "https://api.apify.com/v2/acts/accountable_eel~trademark-filing-watch/run-sync-get-dataset-items?token=<YOUR_TOKEN>" \
-X POST \
-H "Content-Type: application/json" \
-d '{"terms":["cloud"]}'
n8n. Add an HTTP Request node: Method POST , URL https://api.apify.com/v2/acts/accountable_eel~trademark-filing-watch/run-sync-get-dataset-items?token=<YOUR_TOKEN> , Body Content Type JSON , JSON Body {"terms":["cloud"]} (swap in an expression from an earlier node for a real value).
Clay. Add an "HTTP API" column: Method POST , URL https://api.apify.com/v2/acts/accountable_eel~trademark-filing-watch/run-sync-get-dataset-items?token=<YOUR_TOKEN> , Body {"terms":["{{term}}"]} , mapping the row's term into the terms array.
MCP. In Claude, Cursor, or any MCP client with the Apify MCP server, ask for "trademark watch for new USPTO filings" — the agent will find and run this actor.
