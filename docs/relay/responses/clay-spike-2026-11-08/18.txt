You can use the HTTP API in Clay to connect with almost any external tool or database that supports API access. Here’s how to get started:
1. Add an HTTP API action to your Clay workflow.
2. Choose the HTTP method (GET, POST, PUT, PATCH, DELETE) depending on whether you want to retrieve, send, update, or delete data.
3. Enter the API endpoint URL you want to interact with.
4. Configure optional fields :
• Add query string parameters to filter or refine your request.
• Set up the request body (for POST/PUT) using JSON format.
• Add any required headers (like authentication tokens).
5. Remove empty fields from the request to avoid sending blank values.
6. Save your configuration as a template for reuse, or use AI-assisted setup to help generate the request structure.
This integration is low-code and doesn’t require credits if you’re connecting to external tools you already subscribe to. If you need to use an API key, you can find and manage it in your Clay settings under Your Profile. If you encounter issues, double-check your API key and integration settings.
