SRA Solicitors Register Scraper — Solicitor & Firm Records

Scrape solicitor and firm records from the SRA Register, the official solicitor directory for England and Wales. Returns name, SRA ID, regulatory status, current employer, head-office location, and profile URL for both individual solicitors and regulated firms.

SRA Solicitors Register Scraper Features

  • Searches by person name, firm name, or SRA number. All three go in the same searchTerms list.
  • Returns individuals and firms from one search, tagged with record_type so you can split them downstream without guessing.
  • Extracts the regulatory status verbatim — including the ones that matter, like "not practising" and "Not regulated by an approved regulator for legal services".
  • Carries the originating search_term on every record, so a run over 500 names stays attributable to the name that produced each row.
  • Caps per search with maxResultsPerSearch and across the whole run with maxItems.
  • Resumable — a crawl that stops on a cap or a spend limit continues without re-charging you for records already delivered.

Who Uses SRA Register Data?

  • Compliance and KYC teams — Verify that a named solicitor is on the register and currently practising, then keep the check on file.
  • Legal recruiters — Build candidate lists by firm, and use the status field to filter out the records that will waste a call.
  • Law firm BD — Map a competitor's regulated entities and head offices, which is more informative than their website's "our offices" page.
  • Insurers and panel managers — Screen firms against the register before adding them to a panel.
  • Legal tech and data teams — Enrich an existing solicitor dataset with SRA IDs, the closest thing to a primary key the profession has.

How SRA Solicitors Register Scraper Works

  1. Put your search terms in searchTerms — names, firm names, SRA numbers, or a mix.
  2. Each term runs as its own search against the register, up to maxResultsPerSearch results per term. The SRA caps a single search at 1000.
  3. Person and firm results are parsed into one record shape, distinguished by record_type.
  4. Records stream into the dataset as they're found, and maxItems stops the run across all terms once you've had enough.

SRA Solicitors Register Scraper Output Fields

Both record types share one field set. current_employer is populated for people, location for firms, and the unused one comes back empty rather than missing.

Resuming a large crawl

Every run emits a resumeCursor in its Output. If a large crawl stops before it finishes — because it hit maxItems, your spend cap (maxTotalChargeUsd), or was aborted — start a new run with the same input plus that resumeCursor to continue from where it left off. The crawl resumes from the queued work the previous run didn't reach.

  • You are not re-charged for records the earlier run already delivered.
  • Resume within your account's run-retention window — on the free tier, roughly your 10 most recent runs. Once the source run is pruned, its resumeCursor is no longer valid.
  • resumeCursor is opaque — supply it unmodified.

FAQ

How do I search the SRA Solicitors Register in bulk?

SRA Solicitors Register Scraper takes a list of search terms and runs each one against the register, returning the results as JSON. The public register has no bulk export and no API, which is the entire reason this exists.

How much does SRA Solicitors Register Scraper cost to run?

SRA Solicitors Register Scraper charges $0.10 per run start plus $0.002 per record. Screening 500 names at 20 results each runs to roughly $20.

Do I need an account or API key for the SRA Register?

SRA Solicitors Register Scraper needs neither. The register is public; you supply the search terms and nothing else.

Can I look up a solicitor by SRA number?

SRA Solicitors Register Scraper accepts SRA numbers in searchTerms alongside names, so a mixed list of names and IDs works in a single run.

Does it cover Scotland and Northern Ireland?

SRA Solicitors Register Scraper covers England and Wales, which is the SRA's remit. Scotland and Northern Ireland have their own regulators and are not on this register.

Why Use SRA Solicitors Register Scraper?

  • Authoritative — the SRA Register is the statutory source, not an aggregator's copy of it.
  • Bulk-shaped — hundreds of search terms in one run, each record tagged with the term that found it, so reconciling the output against your input list is a join rather than a project.
  • Cheap — $0.002 per record.
