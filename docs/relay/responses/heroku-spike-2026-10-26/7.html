Attachment Scanner

Anti-virus for developers. Scan uploads for viruses, malware and more. Starting at ~$0.138/hour.

Install Add-on

Start Scanning In Minutes

Start scanning user uploaded content and files within minutes. Our JSON API is easy to integrate and quickly lets you scan without overloading your servers.

Built to be Secure

We’ve built our scanning appliances to be secure by default. We use HTTPS encryption for transfer, AES encryption for files at rest and take security very seriously. We can also offer dedicated instances if required.

Scalable

Scan as many uploads as you need to for Viruses, Malware, Phishing, SPAM and more. Our scanners scale to handle as many files as you need when you need them.

Global

We have clusters available in the U.S. and Europe. You can also launch dedicated scanning appliances in any region you need.

Works with any Language / Framework

Our JSON API works with regular HTTPS POST requests. Whatever your preference we can take URLs or direct file uploads and scan them. We’ll even call your servers when the scan is complete if you don’t want to wait for the result.

Scan history

Our dashboard allows you to see matches and details of the scan including the filename, the size of the attachment and a unique hash to identify the upload version.
