How Does It Work?

Find an issue you want to see solved

Browse through the open issues and find the ones you want to see solved. Choose the issues that fit your needs or interests.

Create a bounty for that issue

Set a bounty to attract developers to tackle the issue. If someone already set a bounty, you can add more funds to increase the reward.

Review the proposed solution

Developers can submit a pull request and claim the bounty. Review whether it meets the requirements in the issue.

Arrange payment after approval

When the pull request meets the issue requirements, arrange payment for your own bounty. Each contributor pays their share separately.

Bounties

Use OpireBot commands in repositories where it is installed. Otherwise, create a bounty in the Opire app with the issue URL and amount.
You can create a bounty in any public GitHub repository from the Opire app. In private repositories, commands are available only to people with repository access when OpireBot is installed.

Tips

Help the project and its community. A tip is a direct thank-you, so its sender decides when to create one.
Use the /tip command in a repository with OpireBot installed. Include an amount and the GitHub user you want to thank.
A bounty funds a specific issue; a tip thanks a specific contributor without requiring them to solve an issue.
Yes. Tips are independent of bounties and can be sent for a contribution in an issue or pull request.
