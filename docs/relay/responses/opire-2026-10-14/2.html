Costs & Payments

Use this page to understand the financial commitment before you create a bounty or a tip.

Minimum amounts​

ContributionMinimumCreated for
Bounty$20 USDResolving a GitHub issue
Tip$1 USDThanking a contributor on an issue or pull request

Only code owners can create bounties, and only for issues in their own repositories. More than one code owner may create a bounty for the same issue; each person is responsible only for the bounty they created.

When a bounty is paid​

Creating or claiming a bounty does not create an automatic payment. A developer submits a pull request, then each bounty creator reviews whether it meets the requirements described in the issue. If it does, that creator arranges payment for their own bounty.

Opire publishes and tracks bounties and claims; payments are arranged directly by the people involved. Check the issue requirements and agree on any payment details before you create or claim a bounty.

Tips​

Tips are not tied to resolving an issue. Create one only when you want to thank a specific contributor. Like bounties, a tip is not an automatic platform payment; the sender and recipient arrange payment directly.

Need help?​

Ask in #ask-us on Discord before creating a contribution if the expected payment or repository access is unclear.
