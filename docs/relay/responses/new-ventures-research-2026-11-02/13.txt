The creator monetization program lets Poe bot creators get paid. See program details on the creator monetization program page (https://help.poe.com/hc/en-us/articles/21921312368020-Poe-Creator-Monetization-FAQs) and on the Creators page (https://poe.com/creators) on the Poe website. Part of the program includes setting earnings more flexibly per message from within the bot’s code (see Poe Bot Monetization API Documentation (/docs/server-bots/poe-bot-monetization-api-documentation) ).
If for any reason the above program does not meet your needs as a developer, please reach out to us at [email protected] . (/cdn-cgi/l/email-protection#2f4b4a594a43405f4a5d5c6f5f404a014c404201) We can work out custom arrangements.
