#section/Bienvenue-sur-la-documentation-interactive-d'API-Recherche-d'entreprises-! Bienvenue sur la documentation interactive d'API Recherche d’entreprises !
L’API Recherche d’Entreprises permet à tout le monde retrouver une entreprise,
une association, ou un service public en France. Elle propose un grand nombre de
critères de recherche, en particulier la dénomination, l’adresse et les
dirigeants ou élus.
#section/Bienvenue-sur-la-documentation-interactive-d'API-Recherche-d'entreprises-!/Donnees-accessibles-dans-l'API Données accessibles dans l'API
L’API étant totalement ouverte d'accès, elle comporte des limitations. Ainsi
ne sont pas accessibles dans l'API :
les entreprises non-diffusibles
les entreprises qui se sont vues refuser leurs immatriculation au RCS
Attention : cette API ne permet pas d'accèder aux données complètes de
la base Sirene, mais uniquement de rechercher une entreprise par sa
dénomination ou son adresse. Pour savoir comment obtenir les données
complètes, consultez notre fiche explicative. (https://api.gouv.fr/guides/quelle-api-sirene)
#section/Bienvenue-sur-la-documentation-interactive-d'API-Recherche-d'entreprises-!/Commencer-a-utiliser-l'API Commencer à utiliser l'API
L'API est accessible à partir de cette adresse : https://recherche-entreprises.api.gouv.fr
Attention : Vous devez rajouter votre requête sur l'adresse.
#section/Bienvenue-sur-la-documentation-interactive-d'API-Recherche-d'entreprises-!/Limite-des-requetes Limite des requêtes
L'API accepte au maximum 7 requêtes par seconde par adresse IP. Une limite de 30 requêtes par seconde par ASN est aussi en place. Il est donc probable de faire face à cette limite sur les cloud publics.
Cette valeur correspond à une limite maximale et ne constitue pas un débit garanti.
En cas d'usage excessif, notamment en période de forte activité, l'accès à l'API
peut être temporairement restreint afin d'assurer un accès équitable à l'ensemble
des utilisateurs. La priorité est alors donnée aux systèmes internes et aux
services publics.
Lorsque la limite est dépassée, le serveur renvoie une réponse
HTTP 429 – Too Many Requests .
L'en-tête Retry-After indique le délai à respecter avant d'effectuer
une nouvelle requête.
Il est recommandé d'inclure un en-tête User-Agent explicite et descriptif
dans toutes les requêtes.

#tag/Recherche-textuelle Recherche textuelle
#tag/Recherche-textuelle/paths/~1search/get Recherche textuelle
Cet endpoint permet de récupérer les unités légales et les établissements correspondants à la recherche effectuée sur la dénomination, l'adresse, les dirigeants et les élus. Ou bien par numéro SIREN / SIRET.
Deux modes de recherche selon la valeur du paramètre q :
Recherche textuelle classique (dénomination, adresse, dirigeants, élus) : tous les filtres optionnels ( code_commune , code_postal , departement , region , epci , etc.) sont appliqués en combinaison avec la recherche.
Recherche directe par SIREN ou SIRET : si q contient exactement 9 chiffres (SIREN) ou 14 chiffres (SIRET), l'API effectue une recherche directe et ignore tous les autres filtres . Combiner un SIREN ou SIRET avec des filtres géographiques ou thématiques ne produira pas d'erreur, mais ces filtres seront silencieusement ignorés.
query Parameters
q
string
Termes pour une recherche textuelle (dénomination et/ou adresse, dirigeants, élus) ou recherche directe (SIREN, SIRET).
activite_principale
string
Example: activite_principale=01.12Z,28.15Z
Le code NAF ou code APE, un code d'activité suivant la nomenclature de l'INSEE (https://www.insee.fr/fr/information/2406147) . Ce paramètre accepte une valeur unique ou une liste de valeurs séparées par des virgules. Il ne s'applique qu'à l'unité légale, et non à ses établissements.
categorie_entreprise
string
Enum: "PME" "ETI" "GE"
Example: categorie_entreprise=PME
Catégorie d'entreprise de l'unité légale (https://www.insee.fr/fr/metadonnees/definition/c1057) .
Ce paramètre accepte une valeur unique ou une liste de valeurs
séparées par des virgules.
code_collectivite_territoriale
string
Example: code_collectivite_territoriale=75C
Code affilié à une collectivité territoriale (Commune - code INSEE, EPCI - n° SIREN, Département - Code INSEE + "D" (sauf cas particulier), Région - Code INSEE)
convention_collective_renseignee
boolean
Enum: true false
Entreprises ayant au moins un établissement dont la convention collective est renseignée.
code_postal

string
Example: code_commune=01247,01111
Code commune (INSEE) en 5 caractères (https://www.insee.fr/fr/information/8377162) . Ce paramètre filtre sur les établissements et accepte une valeur unique ou une liste de valeurs séparées par des virgules.
departement
string \b([013-8]\d?|2[aAbB1-9]?|9[0-59]?|97[12346])...
Show pattern
Example: departement=02,89
Code de département en deux ou trois chiffres (https://www.insee.fr/fr/information/6051727) . Ce paramètre filtre sur les établissements et accepte une valeur unique ou une liste de valeurs séparées par des virgules.
region
string
Example: region=11,76
Code de région en deux chiffres (https://www.insee.fr/fr/information/6051727) . Ce paramètre filtre sur les établissements et accepte une valeur unique ou une liste de valeurs séparées par des virgules.
epci
string
Example: epci=200058519,248100737
Liste des epci valides (https://www.insee.fr/fr/information/2510634) . Ce paramètre filtre sur les établissements et accepte une valeur unique ou une liste de valeurs séparées par des virgules.

#tag/Recherche-geographique Recherche géographique
#tag/Recherche-geographique/paths/~1near_point/get Recherche géographique
Cet endpoint prend en paramètre une latitude (:lat) et une longitude (:long) et renvoie les unités légales et leurs établissements autour de ces coordonnées.
Vous pouvez également préciser un paramètre radius en km(défaut: 5 km).
Paramètres d'appel : latitude, longitude, radius, activité principale et section d'activité principale de l'entreprise.
query Parameters
lat
required
number <float>
