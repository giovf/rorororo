Sorry, there is a problem with the service
The Planning Data Platform has been unavailable since Friday 6 November 2026 because of a technical issue.
The disruption may impact MHCLG services including:
Planning Data Platform (https://www.planning.data.gov.uk/)
Planning Data API, and any third party software services using this data
Check and Provide (https://provide.planning.data.gov.uk/)
Planning Data Design (https://design.planning.data.gov.uk/)
Submit a site for a local plan (https://mhclgdigital.blog.gov.uk/2026/10/06/a-faster-start-to-local-plan-making-introducing-the-submit-a-site-for-a-local-plan-tool/)
Users of Extract (https://extract.ai.gov.uk/) can still access the tool directly.
MHCLG’s Digital Planning Programme are working hard to restore services as soon as possible.
Check this page for further updates.
