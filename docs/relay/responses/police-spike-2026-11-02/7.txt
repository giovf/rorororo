Crime categories
Returns a list of valid categories for a given data set date.
Example request
https://data.police.uk/api/crime-categories? date =2024-01
Example response
[
{
"url": "all-crime",
"name": "All crime and ASB"
},
{
"url": "burglary",
"name": "Burglary"
},
{
"url": "anti-social-behaviour",
"name": "Anti-social behaviour"
},
...
]
Response description
Tag
Description
url
Unique identifier
name
Name of the crime category
