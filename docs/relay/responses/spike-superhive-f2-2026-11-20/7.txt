3DMAGIC / COMPOSITOR TOOLKIT
Compositor FX
A powerful Blender compositor toolkit designed to help artists build, refine and reuse professional image looks without rebuilding complex node setups by hand.
68 Ready-to-Use Filters 15 Image Adjustments Custom Node Filters Reusable Looks
What is Compositor FX?
Compositor FX is a complete compositor workflow for Blender artists who want fast access to color grading, cinematic effects, film looks, lens effects, detail processing, stylization and practical image adjustments.
Instead of manually rebuilding node setups for every project, you can browse effects, add them to a stack, adjust their parameters, reorder them, enable or bypass individual effects, and save the complete result as a reusable Look.
Core Features
68 ready-to-use compositor filters
15 dedicated image adjustment controls
Searchable filter browser
Filter categories and favorites
Recently used filters
Adjustable Strength for individual effects
Master Strength for the complete stack
Enable / bypass individual effects
Reorder, duplicate, reset and remove effects
Create custom filters from selected compositor nodes
Save complete effect stacks as reusable Looks
Import and export Looks as JSON
Share custom filters as JSON
Scene render and still-image workflow
15 Image Adjustments
The dedicated Adjust stage provides 15 practical controls for quickly refining the final image. These controls are separate from the 68 filters in the browser.
01 — Light
Exposure — Adjust photographic exposure in stops.
Brightness — Control overall image brightness.
Contrast — Increase or reduce tonal contrast.
Gamma — Adjust midtone brightness.
02 — Levels
Black Point — Set the input black point.
White Point — Set the input white point.
Highlights — Refine brighter image areas.
Shadows — Refine darker image areas.
03 — Color
Saturation — Control overall color intensity.
Hue Shift — Rotate the image hue.
Temperature — Shift the image from cool to warm.
Tint — Shift the image from green toward magenta.
04 — Detail
Sharpness — Enhance fine image detail.
Clarity — Increase local contrast and texture.
Blur — Apply Gaussian-style softening.

Workflow
01 — Choose Your Source
Start from the current scene render or load a still image for grading and export.
02 — Build & Refine
Search for a filter, add it to the stack, tune its parameters and compare the result using Master Strength.
03 — Preview & Save
Preview or render the result, save the image and export a Look to reuse the complete recipe later.
Custom Filters
Create your own reusable filters from selected compositor nodes. Exposed node inputs can be adjusted directly from the panel, allowing you to turn your personal node setups into reusable tools.
Custom filters can also be shared as JSON, making it easier to move your custom setups between projects or share them with other artists.
Looks & Presets
Save a complete effect stack as a Look, including effect order, enabled states, Strength values and parameters. Looks can be exported and imported as JSON for reuse.
Compatibility & Important Notes
Blender Versions:
The add-on is designed for Blender 4.0–5.2. The Extension package requires Blender 4.2 or newer. A separate Legacy package is included for Blender 4.0–4.1.
The supplied code notes test runs on Blender 4.2.23, 4.5.14 and 5.0.1. Blender 4.0/4.1 and 5.1/5.2 were not verified in that environment. Run the included Self-Test before production use on an unverified version.
Performance:
Blender versions before 4.5 are limited to 8 active browser filters per stack. Blender 4.5+ has no fixed cap, but larger stacks and higher resolutions can take longer to process.
A filter whose required node is unavailable is reported and skipped without blocking the rest of the stack.
Other Notes:
Film Grain uses a generated static noise tile. Denoise uses Blender's built-in compositor node. Results may vary depending on source image, resolution, available Blender nodes and color management.
