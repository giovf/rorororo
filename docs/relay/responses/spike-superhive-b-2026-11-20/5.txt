API Access Instructions
Accessing the API
All API endpoints are publicly available via HTTPS.
Base URL (example):
https://superhivemarket.com/api/v1/...
Each endpoint is documented in our API Reference (https://superhivemarket.com/api-docs/index.html) .
Authentication
All requests must include your personal authentication token in a custom header:
1. Generate Your Token
Log into your Superhive account (https://superhivemarket.com/account)
Navigate to:
Account → API Tokens
Click Create Token , naming the token and specifying the scope as needed
Upon creating a token, copy the secret to your clipboard and paste it where needed. The secret will never again be shown, if you lose it you'll need to create a new token.
2. Use the Header
Include your token with every request:
SH-Auth-Token: YOUR_TOKEN_HERE
Important Notes
Treat your auth token like a password.
Anyone with the token can access data available to your Creator account.
If your token is ever compromised, revoke it and generate a new one immediately from the same page.
