Install OpireBot

To allow users to interact with Opire directly within their favorite platform repositories (GitHub), it's necessary for the repository to have an installed bot that enables the use of certain commands within issues and PRs.

This bot manages communication with the Opire API, ensuring that actions performed through commands will be reflected in Opire.

1. Choose repositories in GitHub​

Install OpireBot in GitHub

GitHub will ask you to choose the account or organization and the repositories where OpireBot can operate. Select only the repositories where you want people to use Opire commands.

2. Confirm the installation​

Open an issue in a selected repository and add /reward 20 in a new comment. OpireBot will reply when the command is available. Commands only work when creating an issue, pull request, or comment; editing existing content does not trigger them.

3. Share the next step​

Tell contributors that they can create bounties, try to solve rewarded issues, claim bounties from a pull request, and send tips. Link them to the commands reference.

If the bot is not available, confirm that the repository was selected during installation and that you are creating new content in an issue or pull request. You can still create public-repository bounties from the Opire app.
