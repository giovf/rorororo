This addon helps you change the position of the pivot point as needed. You can align it to the normals of the desired polygon, rotate and move it, or place it in the center of the object and the 3d cursor. You can use BBox to align to the extreme positions. Save position and rotation in a separate panel. The addon brings all the necessary features to the fore, for your convenience.
How often have you had to change the position of your object relative to another, change the amount of opening the lid, door, and so on? Now you can do it in a couple of clicks. The addon is fully integrated into the blender ecosystem and follows all the basic principles of the environment.
Documentation on GitBook (https://max-derksen.gitbook.io/pivot-transform/)
Functions:

- Pivot To Center Of Mesh
- Pivot To Active (With align from axis)
Transform:
This function allows you to improve the use of the standard transformation function.
Pivot Flow:
A function that implements a similar approach to working with a pivot to Maya.
Pivot Drop:
Fast, the function of moving the pivot aligned to the selected items.
Pivot To Bottom:
Move the pivot to the bottom of the object.
BBox:
Moving the pivot to BBox points. You can use this function to find the endpoints of selected objects.
Pivot To Select:
Move the pivot through the selected elements, with the ability to align with the normals.
Pivot Apply(Panel):
Applying a pivot with the ability to use it from edit mode.
Pivot Save(Panel):
Save the position and rotation of the pivot in the panel, with the possibility of applying a separate rotation or position. Thanks Blenderboi (https://blendermarket.com/creators/blenderboi) for help in implementation.
