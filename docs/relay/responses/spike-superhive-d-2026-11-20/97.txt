PHYSICS DROPPER - Easy Rigidbody & Cloth Physics Simulation for Blender
═════════════════════════════════════════════════════════════════════
Transform
complex physics simulations into simple one-click operations. Physics
Dropper makes professional-quality rigid body and cloth simulations
accessible to everyone - from beginners to advanced users.
Stop wrestling with Blender's physics settings. Physics Dropper gives you:
✓ ONE-CLICK PHYSICS SETUP - Just select, press V, and watch it work
✓ MATERIAL PRESETS - Cotton, Denim, Leather, Rubber, Silk - perfectly tuned
✓ INTERACTIVE FORCE FIELDS - Place forces in real-time with mouse and scroll wheel
✓ HIGH-POLY OPTIMIZATION - Automatic proxy creation for heavy meshes
✓ EARTHQUAKE EFFECTS - Add procedural shake to any simulation
✓ SMART BAKING - Convert physics to keyframes with one click
✓ COLLECTION SUPPORT - Apply physics to entire collections instantly
You can grab the full version HERE (https://github.com/Ladypoly/physics_dropper/releases/download/v1.3.2/physics_dropper_1.3.2.zip) https://github.com/Ladypoly/Serpens-Bledner-Addons/blob/main/PhysicsDropper/physics_dropper_1.1.3_free.zip?raw=true for free.
But if you are in a donation mood, and you like to support me and the Blender development fund, then you can buy the addon. 😊

KEY FEATURES
═════════════════════════════════════════════════════════════════════
🎯 RIGID BODY PHYSICS

KEYBOARD SHORTCUTS
═════════════════════════════════════════════════════════════════════
V → Apply physics to selection
Shift+V → Finalize and bake simulation
F → Enter interactive force field mode
All shortcuts are fully customizable in Blender Preferences.

TIPS & BEST PRACTICES
═════════════════════════════════════════════════════════════════════
PERFORMANCE:
✓ Enable proxy for meshes over 10,000 polygons
✓ Start with low substeps (3-5) for preview
✓ Increase quality only for final render
✓ Bake long simulations to keyframes
STABILITY:
✓ Use Split Impulse to reduce jittering
✓ Increase Solver Iterations if objects pass through
✓ Add more Substeps for fast-moving objects
✓ Start with low force values, increase gradually
CLOTH TIPS:
✓ Always have collision objects (floor, body, etc.)
✓ Enable Self Collision for complex folds
✓ Use Pin Group (vertex group) to anchor cloth edges
✓ Increase Collision Quality if penetration occurs

INSTALLATION
═════════════════════════════════════════════════════════════════════
1. Download physics_dropper.zip
2. Open Blender → Edit → Preferences → Extensions
3. Click "Install from Disk"
4. Select downloaded ZIP file
5. Enable "Physics Dropper"
6. Access from 3D Viewport sidebar (press N) → PhyDrop tab
Done! Start simulating in seconds.

VERSION HISTORY
═════════════════════════════════════════════════════════════════════
Version 1.4.1 (Current)
• Rigid bodies already on your objects are saved, removed for a clean setup, and
restored exactly on Apply or Reset
• Drops survive a save, a reload, an undo or a crash - nothing is left welded to
your objects, and a file saved mid-simulation reopens ready to Apply
• Generated colliders no longer inherit stray settings from the meshes they were
built from, which could produce a collider that collided with nothing
• New "Clear All Rigid Bodies" option in World Settings
• Exit Drop Mode now cleans up instead of leaving the collider behind
• Scenes that do not start at frame 1 keep their frame range
• A failed Drop rolls the scene back instead of leaving it stuck in drop mode
• Cloth: rigid bodies in the scene no longer keep falling during a cloth drop -
they are saved, frozen and restored just like in a rigidbody drop
• Cloth: collision already on the collider sources no longer silently overrides
your World Collision Settings
• The Colliders selector now sits directly above the Drop button in both modes
• Fixed: the Remove Simple Force button never appeared
• Blender 4.2 - 5.2 compatibility
Version 1.4.0
• Added a Colliders selector (Auto / List / None)
• Collider list with Add Selected / Add Collection / Remove / Select / Clear
• Hidden objects and objects in excluded collections usable as colliders,
without ever being unhidden
• Current collider mode shown above the Drop button
• Drop warns when no collider will be generated and nothing is collidable
Version 1.3.0
