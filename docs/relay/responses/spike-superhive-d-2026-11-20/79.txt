Random Flow is a random mesh generator designed for fast and easy hard surface prototyping and concept art. This a fast changing add-on with lots of new functionalities in the future.
Use code: bgdiscount25 for 25% discount for the rest of my product after purchasing a single one.
You can also purchase the Preselect (https://superhivemarket.com/products/preselect) add-on as a support tool for this add-on - also in Superhive.
I want to thank Piero Desopo for testing the add-on, finding bugs and improvements. He’s also responsible for some of the cool renders using the plugin. Go check out his art @ http://phoenixart.com
Read the online documentation here: https://www.blenderguppy.com/add-ons https://www.blenderguppy.com/add-ons
Watch the available Youtube videos in the Random Flow playlist (https://youtube.com/playlist?list=PLKFJy6TgdDCIC8rEkGbY09tE0IEn5j5b3&si=CpMx_iaewBgCROQj) here.
This product is also available in the Creative Bundle (http://blendermarket.com/creators/blenderguppy) and other add-ons if you want to purchase that instead.
Latest updates has added the geonode feature to the add-on allowing you to create a modifier based scifi panel details.
This feature has added commands like initiate, edit, copy and remove to give you better controls of the geonode properties.
Random Flow offers tons of greeble based functionalities and other operators that support them.
You can layer the greeble details on top of each other to create interesting designs with functional realism.
The Random Flow add-on can make old and new ideas looks fresh and original.
MAIN FEATURES:
Random Loop Extrude : Creates stacks of greeble mesh for pure randomized chaos.
Random Panels : The OG scifi panel generator.
Random Slice : This creates random slices per face.
Random Axis Extrude : This creates recursive branching extrusions in the xyz axis.
Random Cells : This creates faces the can act is emission planes for buildings or spaceships or extrusions to add antennae like structures as a simple way to break the silhouette.
Random Scatter : Scatters a simple cube, mesh or collections on the active object.
Random Tubes : Creates random tubes or pipes in the form of curves.
Random Cables : Creates catenary or manually controlled cables in the form of curves.
Flanges /Couplings : Creates flanges on curves created using Random Cables.
Panel Screw : Creates screws on face or face group corners.
Panel Cloth : Easily transform selected faces to cloth effects.
Plate Insets : Alternative scifi panel generator using the same solver as Random Starship.
Quick Displacement : Destructive mesh displacement using blender noise or image textures.
Quad Project : Easily quadify angular ngon faces.
Grid Project : Project grid edge cuts on mesh faces.
Straight UV's : Quickly UV randomized meshes from Random Panels or Random Loop Extrude.
...and so much more!
Once you have familiarized yourself to the main random operators and their support tools, the possibility of creating unique details and design will be endless.
* This is a one time purchase and all updates are free.
