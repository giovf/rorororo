TraceGenius Pro and TraceGenius Ultimate (https://superhivemarket.com/products/tracegenius-ultimate) are not the same addon.
Pro uses Blender’s built-in Grease Pencil tracing engine.
Ultimate (https://superhivemarket.com/products/tracegenius-ultimate) uses a fully custom tracing engine with features Blender’s tracer cannot support (color picking, transparency control, pre-trace enhancements, etc.).
If anything is unclear or you have questions about the differences, please contact me. I’m always happy to explain or help
TraceGenius Pro 4.7: Advanced 2D Image to 3D Mesh Tracer
Updated to FULLY support all Blender versions from 2.8 onward — including the latest release and future versions.
The solution for artists and designers seeking precision and efficiency in image-to-3D conversions.
Key Features:
Drag-and-drop or open image files with ease
Extract outlines or faces for customized 3D results
Invert image selection for creative flexibility
Fine-tune with color/brightness thresholds
Extrude and bevel extracted shapes for intricate detailing
Separate individual parts after mesh generation
Utilize an advanced algorithm for clean and efficient mesh/geometry
TraceGenius Pro takes the complexity out of 3D conversion, offering a user-friendly experience with powerful tools for extracting shapes, adjusting details, and achieving superior mesh quality.
Supported Image Formats
TraceGenius Pro supports JPG , PNG and Webp image file formats.
SVG file formats will be fully supported in the next update

How To Install
Open Blender and navigate to Edit → Preferences .
In the Preferences window, go to the Add-ons tab on the left.
Click the Install button at the top of the window.
Locate the downloaded .zip file for TraceGenius Pro on your computer.
Select the file and click Install Add-on .
