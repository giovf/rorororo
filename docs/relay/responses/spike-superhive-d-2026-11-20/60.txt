Procedural Spaceship Generator Addon
1. Overview
The Procedural Spaceship Generator allows you to create sci-fi spaceships by combining customizable components, including a detailed fuselage, swept wings, engines, cockpit, and hull details.
Adjust the proportions and design of each component to create different spaceship styles. The random seed system provides endless design variations.
Key Features:
Procedural spaceship generation.
Adjustable fuselage length, width, and height.
Customizable wings, engines, and cockpit.
Hull details, stripes, antennas, and window lights.
Tail fins, turrets, and wing engine options.
Six built-in spaceship presets.
Custom preset saving and loading.
Procedural materials, textures, and animation.
2. Installation
Download the add-on ZIP file.
Open Blender 4.2.3 or newer.
Go to Edit → Preferences → Add-ons .
Open the small arrow menu in the top-right corner.
Select Install from Disk and choose the downloaded ZIP file.
Enable the add-on using the checkbox next to its name.
Important: Do not extract the ZIP file before installation. Make sure you select the individual add-on ZIP rather than a bundle containing multiple add-ons.
3. Opening the Add-on Panel
Move your cursor over the 3D Viewport.
Press N to open the sidebar.
Select the Procedural tab.
Find the Spaceship Generator panel and expand it.
All Mrs Eliza procedural add-ons share the same Procedural tab.
4. Live Update and Spaceship Generation
The Live Update option is enabled by default. Whenever you change a setting, the spaceship automatically rebuilds after a short pause.
You can also use the refresh button beside Live Update to rebuild manually when automatic updating is disabled.
The add-on maintains a single live object during rebuilding, preserving its position, rotation, scale, parent, and existing modifiers.
Create New: Creates another spaceship at the 3D cursor without changing your existing design.
Randomize Seed: Generates a different spaceship using the same settings. Entering a previous seed allows you to reproduce an earlier design.
5. Creating Your First Spaceship
Follow these steps to generate your first spaceship:
Enable Live Update .
Click Create New to generate a spaceship.
Adjust Fuselage Length, Width, and Height Ratio.
Customize Wing Span and Wing Sweep.
Add or remove engines and adjust their dimensions.
Enable or disable the cockpit and hull details.
Use Randomize Seed to explore alternative designs.
When you find a design you like, click Create New to keep it and continue experimenting with another spaceship.
6. One-Click Setup and Presets
The Presets & Scene section provides ready-made spaceship designs and scene setup options.
Click One-Click Setup to generate a complete example using the default Sleek Fighter preset. It also creates materials and can optionally add a ground plane, sun light, and sky color.
The viewport automatically switches to Material Preview so you can see the spaceship's appearance immediately.
Built-in Presets
The add-on includes six ready-made spaceship presets:
Sleek Fighter
Heavy Cargo Hauler
Battle Cruiser
Stealth Interceptor
Retro Rocket
Alien Bio-Ship
Select a preset and click Apply Preset to generate its design. You can continue adjusting the spaceship afterward.
Custom Presets
Save and reuse your own spaceship configurations:
Save My Preset: Save your current settings under a custom name.
Load My Preset: Restore a previously saved preset.
Delete My Preset: Remove a saved preset.
Custom presets are stored in Blender's configuration folder and remain available across projects.
7. Colors, Materials and Textures
The Color, Material & Texture section allows you to customize your spaceship using procedural shader nodes. No external image textures or UV unwrapping are required.
Colors
Create smooth color gradients using four adjustable color stops. Enable Hard Bands for a stepped, toon-style appearance.
The gradient can follow the texture, object height, or surface slope.
Textures
Choose from procedural textures such as Noise, Voronoi, Wave, and Brick. Adjust scale, detail, distortion, stretch, seed, and bump strength.
Layer Effects
Add secondary color effects such as snow, moss, or dust using adjustable thresholds and breakup controls.
Surface Settings
Customize roughness, roughness variation, metallic, glass, clear coat, opacity, and IOR.
Glow and Color Adjustment
Control glow color and strength, along with hue variation, saturation, and brightness.
Random Look generates a new material combination, while Reset Look restores the default appearance.
You can select different spaceship parts and customize their appearance independently.
8. Animation
The Animation section provides material and object animation controls that work with the timeline.
Material Animation
Flowing Texture: Moves the texture in a selected direction.
Color Cycle: Continuously changes the material's hue.
Glow Pulse: Creates a pulsing glow effect. Set Glow Strength above zero to see the effect.
Object Animation
Choose from four motion types:
Float
Spin
Pulse
Orbit
Adjust speed and amount to control the animation.
Click Stop All Animation to disable all active material and object animations.
9. Settings Guide
The following controls determine the spaceship's shape, proportions, and details.
Main Spaceship Settings
Seed: Controls random generation. Default: 1.
Length: Sets the fuselage length. Default: 20 m.
Width: Controls the fuselage width. Default: 6 m.
Height Ratio: Adjusts the fuselage height proportion. Default: 0.6.
Sections: Controls the number of fuselage cross-sections. Default: 10.
Ring Segments: Sets the number of segments around the fuselage. Default: 12.
Chunkiness: Controls the overall bulkiness of the fuselage. Default: 0.18.
Blunt Nose: Enables a blunt spaceship nose. Disabled by default.
Wing Settings
Wing Span: Controls the overall wing width. Default: 7 m.
Wing Sweep: Adjusts the backward or forward sweep of the wings. Default: 0.18.
Wing Tip Pods: Enables or disables wingtip pods. Enabled by default.
Engine Settings
Engines: Sets the number of engines. Default: 2.
Engine Radius: Controls engine thickness. Default: 0.9 m.
Engine Length: Controls engine length. Default: 3 m.
Wing Engines: Adds engines to the wings. Disabled by default.
Cockpit and Hull Details
Cockpit: Enables or disables the cockpit. Enabled by default.
Hull Details: Controls the number of hull details. Default: 12.
Hull Stripes: Enables or disables decorative hull stripes. Enabled by default.
Additional Details
Tail Fins: Sets the number of tail fins. Default: 1.
Fin Size: Controls tail fin dimensions. Default: 1.
Turrets: Sets the number of turrets. Default: 0.
Antennas: Controls the number of antennas. Default: 2.
Window Lights: Sets the number of window lights. Default: 6.
10. Buttons and Their Functions
The add-on includes several useful actions:
One-Click Setup: Generates a spaceship using the selected preset, materials, and optional scene setup.
Apply Preset: Applies the selected built-in preset, including its settings, appearance, and animation.
Apply Look: Applies procedural materials to the result or selected objects.
Random Look: Generates a new color and texture combination.
Reset Look: Restores the add-on's default color, texture, and animation settings.
Stop All Animation: Disables all active animations.
Add Lighting & Ground: Adds a ground plane, sun light, and sky color to the scene.
Save My Preset: Saves your current configuration.
Load My Preset: Loads a previously saved custom preset.
Delete My Preset: Deletes a saved custom preset.
11. Tips for Better Results
Long, narrow fuselages with swept wings create fast fighter-style spaceships.
Short, wide fuselages work well for cargo ships and heavy spacecraft.
Use Randomize Seed repeatedly to explore different designs.
Click Create New to keep your favorite designs while experimenting.
Add a Subdivision Surface modifier to create a smoother hull.
The generated spaceship is already symmetrical. You can use a Mirror modifier in your own workflow when detailing one side.
12. What Can You Create?
The Procedural Spaceship Generator is suitable for:
Sci-fi game assets.
Futuristic spacecraft concepts.
Space exploration scenes.
Background spaceship fleets.
Sci-fi animations and motion graphics.
Concept art and 3D visualization.

Blender version.
Add-on name and version.
Steps to reproduce the problem.
Full error message from the Info Editor or system console.
Providing these details will help identify and resolve the issue more quickly.
