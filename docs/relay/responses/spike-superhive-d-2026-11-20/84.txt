BoneDynamics 2.0 is a blender addon that allows you to add physics to bones.
Check my youtube page for instructions on how to use this properly :
https://www.youtube.com/watch?v=WhvJYyeoykw
There's also an official discord server where you can get tips and some help :
https://discord.gg/JaeVteJFZT
Check out my new lighting addon Superlight (https://superhivemarket.com/products/superlight)
Features:
Tweak one or multiple bones physics parameters on the fly (Pro)
collision on the entire bone
Bones react to movement and collision.
Super easy to setup.
Ability to stretch bones.
Ability to make a bone chain.
Easy to tweak
Upcoming updates for free.
Enhanced baking system
Dynamic Parenting
Displacement

Rebuilt on cloth modifier (soft body removed)
Fully driver-driven – keyframe any parameter

Hook system for chain pinning and control
Keyframe dynamic bones: Shift+R / Shift+T

Copy/paste bone parameters instantly
