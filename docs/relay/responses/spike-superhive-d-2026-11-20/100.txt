Overview
RizomUV Bridge adds a user interface to Blender for quickly transferring meshes and UV maps between Blender and RizomUV.
✓ One-click transfer to and from RizomUV
✓ Support for multiple UV maps
✓ Quality-of-life features (unwrap using Blender seams, mark UV island boundaries as seams or sharp edges, and more)
✓ Windows support
✓ macOS support Requires Blender 4.2+ and RizomUV 2022.1.35+. See the compatibility table in the documentation.
