Diagnose and repair supported Blender MCP setup problems
Check MCP conflicts, duplicate installations, stale preferences and port collisions with a backed-up repair workflow and Undo.
Safe repair workflow
MCP Doctor does not blindly delete your files.
Before supported repairs, it backs up relevant Blender preferences and affected add-on files. Repairs require explicit user action, including confirmation before quarantining duplicate third-party add-on folders.
Depending on the detected issue, MCP Doctor can disable conflicting MCP add-ons, quarantine duplicate legacy installations, or remove stale Blender preference references.
Successful repairs save Blender preferences.
Undo is built in, including recovery after restarting Blender.
Privacy and permissions
Your MCP configurations stay local. No telemetry. No external data collection.
MCP Doctor reads supported AI-client configuration files (Claude Desktop, Cursor, VS Code and Codex) for diagnostic purposes only. It does not modify or copy these files into repair backups.
The Blender Extension permissions are used exclusively for:
File access: Inspecting local MCP configurations, creating Blender preference backups, and safely quarantining duplicate add-on folders.
Network access: Checking MCP ports on 127.0.0.1 (localhost). No external server communication or telemetry is performed.
Exported diagnostic reports redact sensitive client commands, arguments, environment values, server URLs, working directories, and combined fingerprints.
Reports may still include local file paths and add-on names. Review reports before sharing them.
Backup protection: Version 1.0.4 no longer stores copies of AI-client configuration files. The included README also explains how to remove sensitive legacy backup copies created by older versions.
What's New in v1.0.4
Improved privacy protection and diagnostic report redaction.
Removed AI-client configuration copies from repair backups.
Added explicit Blender Extension permission declarations.
Added confirmation before quarantining third-party add-on folders.
Improved backup and recovery documentation.
Removed unused network diagnostic code.
