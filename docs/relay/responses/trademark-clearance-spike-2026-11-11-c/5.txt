What to read
mode
Optional
#mode
Register = search all 3.6 million UK marks (live, pending and dead). Journal = the IPO's weekly Trade Marks Journal: every newly published application, with its representative and address.
Type: string
Default: register
Options:
register journal
Mark text
searchQueries
Optional
#searchQueries
One or more marks, e.g. "nike", "apple", "brewdog". Register: searched on the mark text. Journal: filters the issue's marks by mark text.
Type: array
Match
matchMode
Optional
#matchMode
How the mark text must match. Measured for "nike" on the register: contains 249, exact 57, begins with 121, whole word 99, similar spelling 3,365.
Type: string
Default: contains
Options:
contains exact beginsWith word fuzzy
Owner / applicant
ownerNames
Optional
#ownerNames
Owner names, e.g. "Nike Innovate C.V.", "Diageo". Register: owner search (alone or with a mark). Journal: applicant name contains.
Type: array
Trade mark numbers
trademarkNumbers
Optional
#trademarkNumbers
Look up numbers, e.g. UK00003904654, 3904654, UK00912101689 (cloned EU mark). Journal mode also takes international registrations, e.g. WO0000001939971.
Type: array
Nice classes
niceClasses
Optional
#niceClasses
Only marks covering any of these classes (1-45), e.g. 25 (clothing), 9 (software), 35 (retail), 42 (SaaS).
Type: array
Status
statuses
Optional
#statuses
Registered, Filed (pending), Expired or Ended. Empty = all. On 2026-10-16: 2,325,043 registered, 72,398 pending, 1,265,253 expired, 11,725 ended.
Type: string[]
Item
Mark type
markTypes
Optional
#markTypes
Word, Figurative (logo), 3D shape, Colour, Sound and so on. Empty = all.
Type: string[]
Item
Vienna codes
viennaCodes
Optional
#viennaCodes
Figurative-element codes for logo searches, e.g. 27.05.21 (letters forming a monogram), 03.01 (cats, dogs). Register only.
Type: array
Filed from
filingDateFrom
Optional
#filingDateFrom
Only marks filed on or after this date (YYYY-MM-DD).
Type: string
Filed until
filingDateTo
Optional
#filingDateTo
Only marks filed on or before this date (YYYY-MM-DD).
Type: string
Filed in the last N days
filedInLastDays
Optional
#filedInLastDays
Rolling window for schedules, e.g. 7 = marks filed in the last week. Overrides "Filed from" when later. 0 = off.
Type: integer
Minimum: 0
Maximum: 36500
Default: 0
Registered from
registrationDateFrom
Optional
#registrationDateFrom
Only marks entered in the register on or after this date (YYYY-MM-DD). Register only.
Type: string
Registered until
registrationDateTo
Optional
#registrationDateTo
Only marks entered in the register on or before this date (YYYY-MM-DD). Register only.
Type: string
Open to opposition now
openToOppositionOnly
Optional
#openToOppositionOnly
Only marks whose opposition period is running today (27,853 on the register on 2026-10-16). In journal mode: published less than two months ago.
Type: boolean
Default: false
Sort
sortBy
Optional
#sortBy
Register order. Journal rows come in the IPO's own order.
Type: string
Default: relevance
Options:
relevance newest oldest name

journalWeeks
Optional
#journalWeeks

Type: integer
Minimum: 1
Maximum: 52
Default: 1

journalIssues
Optional
#journalIssues
Read these issues instead of the latest ones, e.g. 2026/042, 2026/041.
Type: array
Origin

Optional
#origin
UK applications, international registrations designating the UK, or both.
Type: string
Default: all
Options:
all uk international
Representative

Optional
#representation
Keep marks filed with a representative (attorney firm), without one (applicant filed alone), or both.
Type: string
Default: any

any with without

Representative name or address contains any of these, e.g. "Marks & Clerk", "London", "EC4M".

Optional

Default: false
