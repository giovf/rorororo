About Styles & Variables Organizer

It is the first result for "styles to variables" in Figma's search, with about 140,000 users and more than two thousand purchases at $15, and the people it works for love it: "solved 3 days work in 30 mins", "use it every day". The comment thread also shows where it falls down. Nine different commenters describe scans that never finish ("button reads scanning… forever", "waiting 15 minutes, the file is small"), three report that it does nothing when a FigJam connector or a widget is on the page, four that number variables for spacing map wrongly or not at all, and seven are confused about whether the price is monthly, whether a team purchase covers everyone, or why their card is refused. Variables Toolkit is built around those threads: chunked scans you can cancel, widgets and FigJam objects skipped on purpose, padding and gaps linked with "Auto" spacing left alone, and one price spelled out on the listing.

About the free converters

Styles to Variables is a well-liked free plugin for the single job of turning colour styles into colour variables, and if that is all you need it will do. Its comment thread asks for the things it does not do: text styles, converting only some styles rather than all of them, a success message, and Light and Dark styles that come out as one variable with two modes instead of two variables with the same value. Variables Toolkit does those four things, converts text and effect styles with the unlock, and reuses a variable that already has the name instead of creating a duplicate. Variables Pro is a different tool, built for swapping, importing and exporting variables between files; its users report long imports and lost aliases, and it does not convert styles or find unused ones.

If you came here for unused variables

The clean-up report is free. It lists every variable no layer in the open file uses, groups the variables that share a value so you can merge them, and flags aliases whose target no longer exists. One honest limit, which applies to every plugin of this kind: Figma does not let a plugin see how a published library is used in other files, so "unused in this file" is exactly what it says. Deleting the selected variables is part of the $12 unlock.

What Variables Toolkit does not do

  • Relinking detached or local variables to the library variable with the same name is built and ships with the next published version; until Figma publishes it the live listing has the three tabs above. How it works: relink variables after a move.
  • No import or export of variables as JSON or CSS. Several good free plugins do that.
  • No usage across other files. Figma's plugin API only sees the file that is open; we say so rather than guess.
  • Figma Design only, not FigJam or Slides.
